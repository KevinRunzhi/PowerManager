# PowerManager 交互原型

- `PowerManager_动效小样.html`
- 来源：用户于 2026-07-25 提供的设计小样
- SHA-256：`2B4EA612889FF65C01F628F29D0783FD4610442538A1D3798F275536B6DBD1BA`

## 定位

该 HTML 是 PowerManager MVP-A 的视觉、布局和动效参考原型，用于 Flutter 实现时进行对照，不是生产代码，也不是业务规则来源。

参考内容包括：

- 深色单画布与视觉层级；
- 能量球的位置、比例、色温、呼吸与流体感；
- 晨间确认、点击式记录、径向记录、今日概览和实际状态揭示的交互编排；
- 撤销条、提醒条、触觉时机对应的视觉反馈；
- 页面之间“展开”而非传统跳转的连续感。

以下内容不得直接从 HTML 演示逻辑复制为正式业务规则：

- 活动能量变化演示值；
- 当前精力计算与恢复上限；
- 生活日、结算、版本和数据持久化规则；
- 提醒去重与状态保存；
- 原型中的临时文案或测试状态。

这些内容仍分别以 PRD、算法规则、规则配置和技术方案 v2 为唯一来源。

## 运行说明

直接使用浏览器打开 `PowerManager_动效小样.html` 即可查看。文件除 Google Fonts 的 Manrope 字体请求外，其余样式和交互均内嵌；离线时会使用系统字体回退。

首次 Flutter 视觉实现完成后，需要在 Pixel_7 模拟器和至少一台 Android 真机上与该原型逐项对照。
