# 4. 异常与故障路径

## 4.1 数据库 / 准备失败

- 当前日准备失败时首页显示“读取当天状态失败”和“重试”；
- 新增 Widget 回归证明内部异常正文不会展示给用户，点击重试会重新请求；
- 事务失败测试证明总结、写入和规则切换不会留下半写状态；
- 活动保存、删除、晨间、实际状态和设置保存均有面向用户的失败提示。

## 4.2 导出失败与低存储

- 设置页将 JSON 生成、临时文件写入和系统分享统一放在 `try / catch / finally`；
- 任一步失败都会显示“导出失败，请重试”，并恢复导出按钮；
- JSON 内容生成、文件创建和系统分享面板已在 Release 模拟器成功验证；
- 未向模拟器磁盘写入填充文件，因此“磁盘实际耗尽”仍是故障注入空缺，列入
  已知问题 PM-11-02。
