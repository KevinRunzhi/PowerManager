# 1. 完成范围

本阶段已实现不依赖能量球手势的完整记录路径：

```text
首页 “+”
  → 4 个活动大类
  → 对应 6 个子类
  → 6 个固定时长
  → 大致完成时间
  → 保存并重放当前生活日
```

大致完成时间支持：

- 刚刚；
- 15 / 30 分钟前；
- 1 / 2 小时前；
- 自定义今天的时间。

首页同步显示：

- 当前估计精力；
- 当天有效记录数量；
- 每条记录的子类、大类、时长、完成时间和实际应用 delta；
- 编辑入口；
- 逻辑删除入口。

# 2. 应用用例

新增统一 `ActivityMutator` 边界及 `ActivityUseCases` 实现：

## 2.1 CreateActivity

1. 串行化写操作；
2. 使用稳定 `operationId` 做幂等保护；
3. 在事务中调用 `prepare(beforeWrite)`；
4. 再次校验完成时间不在未来且属于当前生活日；
5. 从持久化的当日规则版本读取理论 delta；
6. 插入活动；
7. 从头重放当天；
8. 把全部有效活动的最新 `appliedDelta` 写回；
9. 返回完整当前日投影。

## 2.2 EditActivity

- 只允许编辑当前未结算生活日的有效活动；
- 可修改大类、子类、时长和完成时间；
- 按当日规则版本重新计算理论 delta；
- 保持原 `createdAt`，更新 `updatedAt`；
- 编辑后从最早记录开始完整重放，后续恢复上限随之重新截断。

## 2.3 DeleteActivity

- 使用逻辑删除；
- 重复删除幂等；
- 删除后立即完整重放；
- 默认列表和汇总不再包含已删除记录；
- 导出数据仍保留已删除记录。

# 3. 并发、跨日与失败处理

## 3.1 重复点击

- Sheet 保存期间关闭所有退出和提交入口；
- 同一个 `operationId` 的重复 Create 只产生一条记录；
- 所有活动写操作通过同一串行队列执行；
- 快捷撤销和列表删除同时发生时，第二次删除得到幂等结果。

## 3.2 生活日边界

- 每次创建、编辑和删除都先执行写前准备；
- 保存时再次读取时钟并校验目标生活日；
- 未来时间被拒绝；
- 03:xx 等属于上一生活日的补记时间被拒绝；
- 打开编辑 Sheet 后跨过 04:00，提交会被服务端用例拒绝；
- 已结算历史没有可写入口，直接调用用例也会拒绝。

## 3.3 事务

准备、校验、写入、重放和 `appliedDelta` 刷新位于 Drift 事务边界内。任一步失败均不保留半写状态。

## 3.4 错误恢复

- Sheet 内显示可理解的错误提示；
- 失败后保留当前选择；
- 提交按钮恢复可用，可直接重试；
- 列表删除失败显示提示并保留原记录。

# 4. 5 秒快捷撤销

创建成功后显示撤销条：

```text
写作业 30 分钟 · 估计 -8                  撤销
```

- 撤销调用与列表删除相同的 `DeleteActivity`；
- 撤销窗口固定为 5 秒；
- 显式计时器保证带 Action 的 Snackbar 不会因系统无障碍延时规则无限停留；
- 点击撤销会取消计时器；
- 超时仅关闭快捷入口，记录仍可在当天列表编辑或删除。
