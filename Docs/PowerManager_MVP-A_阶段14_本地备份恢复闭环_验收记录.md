1. 当前只支持 schema v1，不对未来版本做猜测性迁移。
2. 恢复语义是完整替换，不提供合并。
3. 设置页已验证安全副本分享入口和本地文件存在；未在自动化中向外部应用实际发送文件。
4. 模拟器数据库已用于本阶段恢复验收；真机数据没有变化。
5. 后续若升级数据库 schema，必须同时新增备份 schema 迁移和跨版本恢复测试。
