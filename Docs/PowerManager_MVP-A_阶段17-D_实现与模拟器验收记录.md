## 1. 本轮实际修改

### 1.1 径向手势

新增集中参数 `RecordGestureTuning`，最终采用：

| 参数 | 最终值 |
|---|---:|
| 长按激活 | 200ms |
| 大类 / 子类停留确认 | 500ms |
| 时长停留确认 | 500ms |
| 快速移动后的稳定等待 | 90ms |
| 回滑冷却 | 260ms |
| 无动作超时 | 10s |
| 新节点命中扩展 | 12dp |
| 当前节点黏附扩展 | 28dp |
| 球心回退半径比例 | 0.48 |
| 可开始停留的最大速度 | 0.65 logical px/ms |

实现结果：

- 根据 2026-08-12 复测反馈，选中后进入下一层的停留时间由 300ms 提高到
  500ms，降低手指刚进入节点就跳层的概率；
- 快速掠过时先等待稳定，不立即开始停留确认；
- 当前节点使用更大的黏附区，轻微抖动不会切换；
- 只有 ready 状态松手才调用共享的活动创建用例；
- 取消、超时、回退、完成和销毁都会清理停留、稳定、冷却、超时和收尾 Timer；
- 回到球心按层回退，处于大类层时回到球心可取消；
- 点击式 `+` 入口、完成时间步骤、保存和撤销时序均保持原状。

### 1.2 视觉与动效

- 径向菜单继续使用 HTML 小样的弧形层级、错峰入场、节点吸附和球心面包屑环；
- 选中节点的描边、光晕和停留环改为消费当前能量色温；晨间确认后 100 精力使用青绿色；
- 时长节点展示分钟和预计变化值；节点只保留一层语义描边，不再出现重复横线；
- 修复 `easeOutBack` 回弹值超过 1 后传入 `Opacity` 引发的 Debug 红屏：透明度限制在 0～1，缩放仍保留回弹；
- 关闭系统动画时，菜单仍可立即显示和完成必要状态切换，不运行非必要装饰动画。

### 1.3 实际状态与无障碍

- 五档未选择时保持近似中性权重；选择后依次使用灰紫、暖橙、琥珀、天青、青绿色温；
- 保持“一次点击保存后揭示”，没有实现待办 A 的二次确认；
- 实际状态选择支持 200% 字体和滚动触达；
- 实际状态选项补充按钮、选中状态、中文标签和语义点击动作；
- 返回、关闭入口补充中文 Tooltip；
- 晨间确认、活动保存、撤销、实际状态揭示和低精力跨档使用受控触觉映射。
