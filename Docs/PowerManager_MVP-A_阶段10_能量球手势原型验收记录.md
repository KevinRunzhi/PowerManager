# 1. 第二轮修订内容

## 1.1 交互逻辑

- 保留 120ms 长按启动和大类、子类、时长三层状态机；
- 移除按 34 / 88 / 148 logical px 半径即时切层的高敏感方案；
- 改为与 HTML 小样一致的**圆形节点中心命中**，指针必须实际进入节点附近；
- 大类和子类需在同一节点稳定停留 280ms 才进入下一层；
- 时长需稳定停留 160ms 才进入 `ready`，之后松手才允许写入；
- 进入节点使用约 16 logical px 扩展命中区，已吸附节点使用约 30 logical px
  退出滞回区，降低边缘抖动造成的跳项；
- 每次切层后设置 220ms 回滑冷却，避免同一次位移连续跨层或连续回退；
- 回到球心附近只退回一层，并清除该层之后的临时选择；
- 只有完成三层停留确认后松手才写入；提前松手、取消和 10 秒超时均不写入；
- 小屏边缘节点仍会向安全区内收，节点绘制位置与命中位置使用同一份布局结果。

## 1.2 视觉与反馈

- 能量球由静态渐变改为三团柔光缓慢流动，并加入呼吸、外光晕和连续色温；
- 估计透支使用低饱和灰紫和较低透明度，不隐藏负数；
- 节点沿 HTML 小样的上弧分布，以约 30ms 间隔错峰弹出；
- 候选节点放大并出现青色光晕，其余节点降亮度；
- 停留期间绘制环形进度，明确“正在确认”而非立即切层；
- 切层使用淡出、缩放和面包屑环连续过渡；
- 完成后选中节点收束为光点飞回球心；
- 继续复用 `selectionClick`、`mediumImpact`、共享创建用例、5 秒撤销和提醒时序；
- 尊重系统减少动态效果设置，关闭持续流动并缩短非必要动画。

实现仍保持动画层与业务层分离：动画只维护候选状态，正式写入仍以
`ActivityMutator.create` 为唯一入口。
