# 2. 首页正式状态

首页当前结构：

1. 晨间状态入口；
2. 能量球及常驻“估计精力”标签；
3. 当前估计大数字；
4. “初始值 + 估计档位”文字；
5. 非阻断提醒插槽；
6. 能量球下方 `+` 点击记录；
7. 当天记录列表；
8. 今日概览 / 实际状态 / 此刻校正工具带。

边界：

- 100 不被描述为上限；
- 初始值和当前值可高于 100；
- 当前值可为 0 或负数；
- 负号和大数字由自适应缩放保证不截断；
- 状态同时使用文字，不能只靠颜色；
- 能量球具备完整语义标签；
- 200% 字体缩放和 640 × 360 紧凑横屏均无核心布局溢出。

加载与错误：

- 数据准备期间显示加载状态；
- 数据库或派生失败时显示“读取当天状态失败”；
- 提供重试按钮；
- 错误不会伪造一个默认估计。

# 3. 今日概览

概览默认隐藏，通过“今日概览”按钮以底部 Sheet 展开。

每张大类卡片展示：

- 大类名称；
- 总时长；
- 变化总量 `grossDelta`；
- 右侧估计净变化 `netDelta`。

排序使用 gross 而不是 `abs(net)`。例如同一类恢复 +10、消耗 -10：

```text
netDelta   = 0
grossDelta = 20
```

该类仍排在高活动量位置，不会因抵消而消失。没有活动时显示明确空状态。

# 4. 估计低值提醒

提醒档位：

| 档位 | 文案 |
|---|---|
| 中低 | 估计精力已低于今日初始的一半。 |
| 低 | 估计精力已进入今日较低区间。 |
| 透支 | 当前负荷估计已超过今日储备。 |

提醒特性：

- 始终明确使用“估计”；
- 使用首页内联条，不使用弹窗；
- 可手动关闭；
- 同一生活日同一档位只创建一次 `prompt_receipt`；
- 不同档位分别记录；
- 并发检查通过串行服务避免重复 receipt；
- 正常档位不创建 receipt。

## 4.1 与撤销窗口的时序

创建活动前即把全局 undo window 标记为 active，避免 Sheet 关闭与首页重建之间的竞态。

```text
开始创建
  → suppress reminder
  → 保存
  → 5 秒撤销条
  → 撤销：删除记录并解除 suppress
  → 或超时：关闭撤销条、重新读取当前 projection
  → 根据最新档位决定是否生成提醒
```

因此提醒不会在撤销条仍可操作时抢占注意力，也不会使用创建瞬间的过期 projection。

补做晨间、编辑活动或冷启动导致档位变化时，首页也会从最新 projection 幂等检查提醒。
