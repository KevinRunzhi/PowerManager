# 精力值管理产品 MVP-A Backlog v2

## 0. 验收基线

本 Backlog 只承接《精力值管理产品 PRD v2（MVP-A）》。

优先级：

- P0：7 日自用闭环必需
- P1：自用体验完整性
- P2：验证后再做

---

# EPIC 1：工程与数据骨架

## US-1.1 Flutter Android 工程可运行

优先级：P0

验收：

- Android 真机可启动
- Riverpod 不依赖 codegen
- Drift 数据库可创建和迁移
- Debug 构建能查看生活日、规则版本和派生结果

## US-1.2 最小数据模型

优先级：P0

只建立：

- app_settings
- morning_check_ins
- activity_records
- energy_observations
- daily_summaries
- prompt_receipts
- rule_config_versions

验收：

- 不建立可变 DailyEnergyState
- 不建立 CalibrationCycle、SubcategoryPersonalFactor 或独立 CalibrationFeedback
- 唯一约束和外键通过数据库测试

---

# EPIC 2：生活日与派生计算

## US-2.1 生活日归属

优先级：P0

验收：

- 03:59:59 属于前一生活日
- 04:00:00 属于新生活日
- 时间戳以 UTC 保存，lifeDay 创建时按本地时区持久化

## US-2.2 当前日派生

优先级：P0

验收：

- 初始估计来自基准线、早间综合状态和短期修正
- 活动按 `completedAt, createdAt, id` 稳定重放
- 恢复上限正确
- 只处理有效记录
- 不持久化可变每日实时状态

## US-2.3 幂等结算

优先级：P0

验收：

- 启动、回前台和业务写操作前复用同一准备流程
- 持续前台跨过 04:00 后写入前先结算
- 一个生活日最多一个 DailySummary
- 重复调用不重复结算
- 空生活日不生成摘要

---

# EPIC 3：早间确认

## US-3.1 四项早间输入

优先级：P0

输入：

- 综合状态
- 可自由安排时间
- 压力来源
- 睡眠恢复感

验收：

- 只有综合状态按 `-6 / 0 / +6` 进入初始估计
- 其他三项只保存上下文
- 可跳过，跳过不阻断记录
- 每生活日最多一条

---

# EPIC 4：活动记录

## US-4.1 点击式完整记录

优先级：P0

验收：

- 可选择 4 大类、24 子类、6 个时长档位
- 四个“其他”均可用
- 夜间睡眠不作为活动；普通列表显示“午睡 / 小睡”
- 创建后首页估计和今日概览更新

## US-4.2 当前生活日补记与编辑

优先级：P0

验收：

- 可补记并选择大致完成时间
- 可编辑活动、时长和完成时间
- 编辑就地更新并刷新 updatedAt
- 编辑使用所属生活日的规则版本
- 每次修改后完整重放当天

## US-4.3 删除与快捷撤销

优先级：P0

验收：

- 5 秒内可快捷撤销
- 超过 5 秒仍可从当天列表删除
- 删除写入 deletedAt，不物理删除
- 删除后只重放有效记录

## US-4.4 已结算历史只读

优先级：P0

验收：

- 结算后不能编辑、删除或补记该生活日
- 历史继续展示原 ruleVersion 和结果

# EPIC 5：双轨状态

## US-5.1 首页估计精力

优先级：P0

验收：

- 页面明确使用“估计精力”
- 100 的说明是默认尺度，不是生理满值
- 估计可高于 100 或低于 0

## US-5.2 每日实际状态

优先级：P0

验收：

- 五档：耗尽 / 偏低 / 尚可 / 良好 / 充足
- 每生活日最多一条
- 用户先选择，再看到系统估计差异
- 可跳过
- 下一生活日可补充上一生活日状态

## US-5.3 随时校正

优先级：P0

验收：

- 三档：比估计低 / 差不多 / 比估计高
- 保存发生时间和当时估计
- 不直接覆盖估计
- 不触发自动参数更新

---

# EPIC 6：展示与复盘

## US-6.1 今日概览

优先级：P0

验收：

- 展示大类总时长和净变化
- 按 grossDelta 排序
- 随当天记录变化实时更新

## US-6.2 估计档位提醒

优先级：P1

验收：

- 文案明确是估计状态
- 同日同档最多一次
- 5 秒撤销窗口结束后展示
- 不弹窗阻断

## US-6.3 昨日描述性总结

优先级：P1

验收：

- 区分昨日和更早的上次记录日
- 展示估计、实际状态、活动分布和校正
- 不生成能力评价或参数建议

## US-6.4 滚动 7 个有效日总结

优先级：P1

验收：

- 使用最近 7 个有效日，不建立 CalibrationCycle
- 只做描述性汇总
- 不自动调整基准线或活动规则

# EPIC 7：能量球交互

## US-7.1 能量球展示与点击入口

优先级：P0

验收：

- 能量球展示当前估计
- 点击可进入完整记录流程
- 手势未完成时不阻塞记录

## US-7.2 连续滑动手势原型

优先级：P1

验收：

- 与点击入口复用同一业务用例
- 支持选择、回滑和取消
- Android 真机 20 次独立任务至少成功 18 次
- 不产生错误记录后才可设为默认主入口

# EPIC 8：设置、导出与说明

## US-8.1 个人基准线

优先级：P0

验收：

- 默认 100
- 可手动设置 60～140
- 下一生活日起生效
- 不重算当前日和历史

## US-8.2 规则版本

优先级：P0

验收：

- 内置 `energy-rules-v2-mvp-a`
- 新版本只从下一生活日起生效
- MVP-A 无规则迁移入口

## US-8.3 JSON 导出

优先级：P1

验收：

- 包含 schemaVersion、exportedAt 和规则版本
- 包含七类核心数据
- 包含逻辑删除记录
- 不包含设备秘密或无关系统信息

## US-8.4 精简首次说明

优先级：P1

必须解释：

- 估计与实际分离
- 100 是默认尺度
- 当前生活日可纠错
