# 4. 边界与后续

1. 本阶段不评价估计算法准确性；真实数据仍缺少每日实际状态作为对照基准。
2. 不启动自动学习。至少积累 14 个同时具备有效活动与每日实际状态的有效日后，再单独立项评估。
3. 不补填昨日以前的历史状态，避免回忆偏差污染验证数据。
4. 真机触控、动效和长周期稳定性统一留到 MVP-B 完成后的综合验收。
