# 4. 设计检查

`ui-ux-pro-max` 规则用于检查触控尺寸、渐进披露、动态字号、语义标签和减少动态效果。
外部工具给出的配色与字体建议没有采用，因为本项目现有“呼吸流体”色温轴和文字令牌是更高
优先级的正式设计来源。

实际界面保持两列六项结构，估计值不会遮挡操作，也未增加新的页面跳转或装饰性动画。

3. 本阶段不调整任何规则值；
