# 6. 限制与后续

1. 只保留最近一次主动本机备份，不提供多版本管理；
2. latest 位于应用支持目录，卸载 App 可能被系统删除，重要备份仍应通过分享导出到外部位置；
3. 当前只支持 schema v1；未来升级必须同步增加备份迁移和跨版本测试；
4. 体检失败只报告至少 1 项异常，不在 UI 自动修复或暴露私人明细；
5. 当前实际状态覆盖仍为 0 / 6，因此不得进入 MVP-B 自动个性化；
6. 下一步应继续日常使用并完成每日实际状态，先重新满足 7 日自用验收，再积累到 14 日讨论门槛；
7. 真机触控、触觉、profile 60fps 和 20 次手势任务仍留到 MVP-B 完成后统一执行。
